// EJERCICIO 01 — SERIE DE FIBONACCI

Plan de Ahorro Progresivo con Fibonacci

Una persona desea ahorrar dinero de forma creciente cada mes, siguiendo la serie de Fibonacci. En lugar de depositar montos fijos, cada mes se suma lo ahorrado en los dos meses anteriores, generando un crecimiento orgánico y sostenible, ideal para hábitos financieros graduales.

Diagrama del algoritmo
🚀 INICIO
Leer: número de meses N
Inicializar:
a=1, b=1, suma=0, mes=1
¿mes <= N?
SÍ ✓
Mostrar fila: mes, ahorro=a
suma += a
c = a + b
a = b  |  b = c
mes++
NO ✗
Mostrar tabla
+ Total ahorrado
🏁 FIN
Explicación paso a paso
  • 01
    Inicialización: se definen a = 1 y b = 1, que representan el ahorro del mes 1 y mes 2 respectivamente (los dos primeros términos de Fibonacci).
  • 02
    Bucle iterativo: un for recorre desde el mes 1 hasta N. En cada iteración se registra el ahorro del mes actual (a).
  • 03
    Avance de la serie: se calcula c = a + b (siguiente término), luego a = b y b = c, moviendo la ventana de dos valores hacia adelante.
  • 04
    Acumulador: la variable suma va sumando todos los ahorros para mostrar el total al final. document.getElementById() actualiza la tabla en pantalla.
  • 05
    Sin arrays: el algoritmo usa solo variables simples (a, b, c), lo que lo hace eficiente en memoria. La complejidad es O(N) en tiempo y O(1) en espacio.
Código JavaScript
script.js // ── Ejercicio 1: Ahorro con Fibonacci ────── function calcularAhorro() { // Leer el valor del formulario mediante getElementById const meses = parseInt( document.getElementById("meses").value ); // Validación de entrada if (isNaN(meses) || meses < 1 || meses > 40) { mostrarError("ej1Error", "Ingresa un número entre 1 y 40"); return; } // Variables de la serie Fibonacci (sin arrays) let a = 1, b = 1, c; // a=mes actual, b=siguiente let suma = 0; // acumulador del total let html = ""; // Construir filas de la tabla for (let i = 1; i <= meses; i++) { suma += a; // sumar ahorro de este mes html += `<tr> <td>Mes ${i}</td> <td>Bs. ${a}</td> <td>Bs. ${suma}</td> </tr>`; // Avanzar la serie: c = a + b, luego a←b, b←c c = a + b; a = b; b = c; } // Inyectar HTML usando getElementById document.getElementById("tablaAhorro").innerHTML = html; document.getElementById("totalAhorro").textContent = "Bs. " + suma; document.getElementById("resultAhorro").classList.add("active1"); }
Probar el ejercicio
⚠ Ingresa un número entre 1 y 40.
← Ingresa la cantidad de meses y presiona el botón para ver tu plan de ahorro Fibonacci.
¿Por qué Fibonacci para ahorrar?
  • 💡
    El crecimiento es gradual y natural: los primeros meses el esfuerzo es mínimo (Bs. 1, 1, 2…) y aumenta conforme el hábito se consolida.
  • 📈
    A largo plazo el ahorro escala exponencialmente, similar al crecimiento compuesto en finanzas, pero sin necesidad de calcularlo explícitamente.
  • 🧠
    Psicológicamente es más fácil de cumplir: el compromiso crece junto con el hábito, reduciendo el abandono del plan.
Casos de prueba
🎯
Conclusión: La serie de Fibonacci modela el ahorro progresivo de forma matemáticamente elegante. El algoritmo sin vectores demuestra que la eficiencia no requiere estructuras complejas: con solo tres variables (a, b, c) y un bucle, se genera una secuencia infinita. Este patrón aparece en la naturaleza, el diseño y las finanzas porque optimiza el crecimiento de recursos limitados.

// EJERCICIO 02 — NÚMEROS PRIMOS

Verificador de Seguridad — ¿Es primo tu código?

Los números primos son la base de la criptografía moderna (RSA, HTTPS, firmas digitales). Un número es primo si solo es divisible entre 1 y sí mismo, lo que lo hace impredecible y difícil de factorizar, perfecto para generar claves de acceso seguras.

Diagrama del algoritmo
🚀 INICIO
Leer número N
¿N <= 1?
SÍ ✓
NO es primo
(caso especial)
NO ✗
contador = 0
i = 1
¿i <= N?
SÍ ✓
¿N % i == 0?
→ contador++
i++
NO ✗
¿contador == 2?
✅ PRIMO  |  ❌ NO PRIMO
🏁 FIN
Explicación paso a paso
  • 01
    Lectura: se obtiene el número N desde el formulario con document.getElementById("numero").value y se convierte a entero con parseInt().
  • 02
    Caso base: si N ≤ 1, se rechaza inmediatamente. Los números 0 y 1 no son primos por definición matemática.
  • 03
    Conteo de divisores: un bucle prueba cada número i desde 1 hasta N. Si N % i === 0 (el residuo es cero), i es divisor: se incrementa contador.
  • 04
    Veredicto: si contador === 2, el número tiene exactamente dos divisores (1 y él mismo) → es primo. Cualquier otro valor → no es primo.
  • 05
    Versión optimizada: el algoritmo también muestra los divisores encontrados para visualizar por qué un número no es primo, mejorando la comprensión didáctica.
Código JavaScript
script.js // ── Ejercicio 2: Verificador de número primo ── function verificarPrimo() { const numero = parseInt( document.getElementById("numero").value ); // Validar entrada if (isNaN(numero) || numero < 1 || numero > 999999) { mostrarError("ej2Error", "Ingresa un número entre 1 y 999999"); return; } // Casos especiales if (numero <= 1) { mostrarResultadoPrimo(false, numero, [], "Caso especial: ≤ 1"); return; } let contador = 0; let divisores = []; // para mostrar al usuario // Buscar todos los divisores (algoritmo del PDF) for (let i = 1; i <= numero; i++) { if (numero % i === 0) { contador++; divisores.push(i); } } // Un primo tiene EXACTAMENTE 2 divisores: 1 y él mismo const esPrimo = (contador === 2); // Mostrar resultado en la página mostrarResultadoPrimo(esPrimo, numero, divisores, esPrimo ? `Solo divisible entre 1 y ${numero}` : `Tiene ${contador} divisores` ); }
Probar el verificador
⚠ Ingresa un número entre 1 y 999999.
← Ingresa un número y presiona el botón para saber si puede usarse como clave segura.
¿Por qué los primos protegen datos?
  • 🔑
    El algoritmo RSA (que protege el 80% del tráfico web) funciona multiplicando dos números primos enormes. El resultado es fácil de calcular pero extremadamente difícil de factorizar.
  • 🛡️
    Una clave de 2048 bits usa primos tan grandes que factorizarlos llevaría millones de años con las computadoras actuales.
  • ⚡
    Cada vez que tu navegador muestra 🔒 (HTTPS), está usando números primos para cifrar tu información en tiempo real.
Casos de prueba
🎯
Conclusión: Contar divisores es la forma más directa de verificar si un número es primo. Aunque para números muy grandes existen algoritmos más eficientes (Miller-Rabin, AKS), el método del PDF (contador === 2) es perfecto para comprender el concepto: un primo solo se divide entre 1 y sí mismo. Esta propiedad única hace que los primos sean el pilar de la seguridad informática global.

// EJERCICIO 03 — FIBONACCI & PRIMOS COMBINADOS

Primos de Fibonacci — Patrones en la Naturaleza

Los números de Fibonacci que también son primos se llaman Fibonacci primos. Aparecen en la disposición de pétalos, espirales de caracoles, ramas de árboles y semillas de girasol. Este ejercicio genera la secuencia Fibonacci, la evalúa término a término y resalta los que son primos.

Diagrama del algoritmo combinado
🚀 INICIO
Leer cantidad N de términos
a=1, b=1, i=1
fibPrimos=0
¿i <= N?
SÍ ✓
actual = a
¿esPrimo(actual)?
→ contadorDiv
→ mostrar chip
c=a+b; a=b; b=c
i++
NO ✗
Mostrar chips
+ resumen
+ tabla completa
🏁 FIN
Explicación paso a paso
  • 01
    Generación Fibonacci: el bucle externo genera cada término con las variables a y b usando el mismo patrón del Ejercicio 1 (sin arrays).
  • 02
    Sub-función esPrimo(n): para cada término Fibonacci se invoca la verificación de primalidad del Ejercicio 2. La reutilización de código demuestra modularidad.
  • 03
    Clasificación visual: los términos se muestran como chips de colores: verde con estrella ★ si son primo-Fibonacci, azul si solo son Fibonacci regulares.
  • 04
    Tabla detallada: además de los chips, se genera una tabla completa con el índice, el valor Fibonacci, si es primo y sus divisores. Todo usando getElementById.
  • 05
    Resumen estadístico: al final se muestra cuántos Fibonacci-primos se encontraron y qué porcentaje representan del total de términos analizados.
Código JavaScript
script.js // ── Ejercicio 3: Fibonacci + Primos combinados ── // Sub-función: verificar si n es primo function esPrimo(n) { if (n <= 1) return false; let contador = 0; for (let i = 1; i <= n; i++) { if (n % i === 0) contador++; } return contador === 2; } function calcularFibPrimos() { const terminos = parseInt( document.getElementById("terminos").value ); if (isNaN(terminos) || terminos < 1 || terminos > 25) { mostrarError("ej3Error", "Ingresa entre 1 y 25 términos"); return; } // Variables Fibonacci (sin arrays) let a = 1, b = 1, c; let chips = ""; let filas = ""; let contPrimos = 0; for (let i = 1; i <= terminos; i++) { const primo = esPrimo(a); // verificar primalidad if (primo) contPrimos++; // Chip visual chips += `<span class="fib-chip ${primo?'is-prime':''}"> F(${i})=${a} </span>`; // Fila de tabla filas += `<tr> <td>F(${i})</td> <td>${a}</td> <td>${primo?'✅ SÍ':'❌ No'}</td> </tr>`; c = a + b; a = b; b = c; // avanzar serie } // Inyectar todo en el DOM mediante getElementById document.getElementById("chipsFib").innerHTML = chips; document.getElementById("tablaFib").innerHTML = filas; document.getElementById("contPrimos").textContent = contPrimos; document.getElementById("resultFib").classList.add("active3"); }
Probar el ejercicio
⚠ Ingresa un número entre 1 y 25.
← Ingresa la cantidad de términos y presiona el botón. Los chips verdes ★ indican Fibonacci-primos.
Fibonacci primos en la naturaleza
  • 🌻
    Los girasoles tienen F(12)=144 espirales, pero los pétalos de muchas flores corresponden a términos Fibonacci-primo: 2, 3, 5, 13…
  • 🐚
    La espiral de Fibonacci sigue la razón áurea φ ≈ 1.618, y curiosamente los índices de los Fibonacci-primos tienden a ser ellos mismos primos.
  • 🌿
    Se conjetura que hay infinitos Fibonacci-primos, pero solo se conocen unos pocos, lo que los convierte en uno de los problemas abiertos de las matemáticas.
Casos de prueba
🎯
Conclusión: Combinar Fibonacci y primos revela que estas dos secuencias matemáticamente independientes se intersectan de forma sorprendente. El algoritmo demuestra la potencia de la reutilización de funciones: esPrimo() trabaja dentro del bucle Fibonacci, convirtiendo dos problemas separados en uno integrado. Estos patrones no son accidentes: la naturaleza y las matemáticas comparten una gramática común basada en la eficiencia y la primalidad.
